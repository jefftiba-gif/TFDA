# TFDA IRB 多中心審查暨送審平台 — 互動雛型

依據緯謙科技提交 TFDA 之《TFDA IRB 多中心審查暨送審平台 初步規畫建議書》（Word 提案文件）整理出的角色、業務流程與功能規劃，建置之可互動前端雛型（React + TypeScript + Vite + Tailwind CSS v4）。

## 已實作頁面

- **首頁角色選擇**：試驗贊助者／主審 IRB／副審 IRB／TFDA 管理員／CDE 協調員／系統管理員
- **工作站儀表板**：§6.1 三大區塊（我的待辦／進行中監控中／歷史與歸檔）、急迫性清單、工作清單、行事曆
- **流程控制架構**：案件狀態流（9 種）、三層級控制架構、輪序指派機制、副審審查方式、變更/撤案/結案、§6.2 實現邏輯
- **簡易審查查檢表**：可勾選查檢項目、必填完成度、主副審不一致情境、簡審法規依據
- **案件管理**：案件清單查詢
- **HIS／CDSS 互動模擬**（`/his-sim`，首頁與各頁 Header 皆有入口）：模擬醫師於 HIS 選擇病患、開立處方、觸發 CDSS 藥品交互作用檢核，依規則引擎（過敏史、抗凝血併用、Statin＋Macrolide、腎功能劑量、重複治療）回傳結果進行風險分級，並依 Hard Stop／Soft Stop 分流處置，含覆核理由填寫與 Session 醫囑照會紀錄
- 其餘側邊欄項目為規劃中頁面（Placeholder），對應提案書之核心功能清單，待需求訪談後逐步落地

此雛型所有資料皆為示意用之模擬資料（mock data），尚非正式系統規格或報價承諾。

## 開發

```bash
npm install
npm run dev      # 本機開發伺服器
npm run build    # 產生 production build
```
